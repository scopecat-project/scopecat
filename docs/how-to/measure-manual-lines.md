# 手动换线并逐条测量 {#measure-manual-lines}

用一个保存的测量模板建立有限、有序的物理线路清单，逐条检查接线、采集并比较尝试。
例如依次测量冰箱输入线 A、B，再重测 A。这里的线路标签不是样品身份，
线路清单也不是降温或装样等[实验批次](experimental-batches.md)。
此流程用于单机、人工换线，最多 1,000 条线路；不会自动切换接线。

## 保存共同模板

在**实验**页选好实验、参数、实验配置以及需要的科学对象和批次。
检查输入并**预览**，再**保存计划**作为共同模板，见[保存实验计划](save-experiment-plans.md)。
保存不采集、不确认接线。清单保留模板的源码和科学范围；它不把线路名转换为样品或目标。

## 建立并打开清单

进入**实验 → 复用与恢复**中的物理线路清单区域（当前标题 **Physical line scans**）。
展开 **Create a line list**，选择刚保存的测量模板，填写清单名、操作者及线路标签，每行一条，
然后 **Save line list**。保存顺序决定下一条尚未尝试的线路。
可以编辑线路显示名，但稳定线路 ID 和顺序不变，历史尝试仍保留当时标签。

在 **Line list** 中选择清单即可读取已有状态和尝试。打开、刷新或重开清单不会提交实验、
派发 worker 或确认接线。同名清单和线路不能仅靠名称区分，需核对所选清单及精确尝试。

## 准备一条线路并显式确认接线

1. 对下一条未尝试线路选择 **Prepare**，打开既有实验准备表单。核对显示的线路；
   可修改频率范围、功率等普通采集输入，不能借此替换模板保留的源码、科学对象、目标或 setup。
2. 检查本次输入及预览，再显式**开始采集**。这会创建持久 procedure，
   先等待人工接线判断；在判断完成前不开始该线路的子运行采集。
3. 在该 procedure 的待处理判断中，核对物理线路、采集意图与原配置，实际检查当前接线，
   填写**判断操作人**，将 `confirmed` 选择为 `true`，再**提交判断并继续**。
   一次确认只对应这条线路的这次采集，不能授权另一采集。
4. 等待运行结果，打开该尝试的曲线和结果。若 procedure 尚未关闭或子运行仍待处理，
   先处理原尝试，不能跳过阻塞直接提交下一条线路。

界面不会检测真实接线，也不证明物理安全。需要停机或更改接线时，按实验室设备流程操作。
点击提交或请求停止，不等于设备已经完成或安全停止。

## 找回、重测并比较尝试

清单逐条显示全部尝试。打开 **Attempt** 查看对应 procedure；
通过 **Curve and result** 读取该次运行，通过 **Recorded settings and source** 核对原源码和实际输入。
需要再测时，对已测线路选择 **Remeasure**，重新准备、检查并确认接线。
重测追加独立尝试，不覆盖旧记录，也不自动把最后一次选为有效结果。

对两个有运行记录的尝试勾选 **Compare this attempt**，检查显示的设置差异后，
打开 **Compare retained curves**。比较使用两个精确运行及各自原始网格，
不插值或强行合并为矩形数据。若要保存比较结论，再按
[保留运行比较](retained-run-comparison.md)操作；阅读曲线本身不会新建分析或采集。

## 退出后重开与异常处理

重开同一应用和作者目录后，在同一数据空间重新选择原清单，读取各线路的保留尝试。
读取不会自动开始下一条；要继续测量需显式准备并检查当下接线。
缺少模板源码时，恢复其受支持的精确源码后再准备，不能改用当前同名定义冒充原模板。

| 状态 | 应做的事 |
| --- | --- |
| 等待资源 `resource_wait` | 查看占用者；由 GUI 管理的 procedure 在资源可用时按原请求唤醒，不需新建一次尝试。 |
| 原子运行尚未启动，确认已过期 | 进入原运行，核对原线路及配置，检查当前接线后显式重新确认，继续同一运行。 |
| 已有执行片段且效果未知 | 先核实并处理外部仪器状态，按既有恢复流程继续或关闭；接线重确认不能解除未知效果。 |
| 确认请求响应丢失 | 重试保留的同一确认请求并刷新状态；旧回执不是服务重启后的新确认。 |

未启动运行的重新确认入口当前为 **Confirm current line wiring**：填写操作者，
勾选已核对接线与配置，再点击 **Confirm wiring and continue**；响应未知时使用
**Retry saved confirmation**。这个入口只继续原未启动运行，不用于已执行后的未知效果。

历史未知尝试仍显示不确定，已有显式核实处理证据允许后续尝试时，也不把旧结果改写为成功。
关闭记录不等于恢复成功。详细边界和可恢复运行见[恢复中断运行](resume-interrupted-runs.md)；
需保存软件故障证据时见[收集诊断](collect-diagnostics.md)。

确认新鲜度、接纳事务和恢复协议由[维护者协议](../development/architecture/manual-lines.md)定义，
本页只说明用户操作，不另设执行或恢复状态。
