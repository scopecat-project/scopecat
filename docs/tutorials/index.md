# Tutorials

Tutorials provide complete learning paths rather than exhaustive interface
descriptions.

- [Edit and analyze a starter experiment](starter-authoring.md) continues the
  installed quickstart with parameters, scans, analysis and retained results.
- [Help lessons](teaching-sandboxes.md) provide resettable peak practice and a
  persistent Notebook topics in ordinary editable author folders.

Parameters, source refresh, computation, grouped analysis and calibration share the
application's preparation and continuation flow. Course ordering, difficulty and
possible grouping still need teaching-design review; technical integration does not
establish unfamiliar-user learning success. The old reference gallery is retired as teaching material;
its remaining scripts are temporary integration-test inputs, not author examples
to copy. See the [retirement inventory](../development/reference-gallery-retirement.md).
