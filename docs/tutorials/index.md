# Tutorials

For a first Notebook experiment, open **Help → Learn with Notebooks → Parameters
and scans**. Run a synthetic scan, inspect its retained result in the application,
then edit the Python source and run again. Help prepares the editable author
folder and its Python environment without source-registration forms.

- [Choose a Notebook route](teaching-sandboxes.md#choose-a-notebook-route) explains
  what each of the seven topics teaches, suggested knowledge and completion goals.
  Continue with source editing, choose computation or grouped analysis as needed,
  and leave multi-step calibration until you need it. You do not need all seven.
- [Practice in Scopecat](teaching-sandboxes.md) starts with a synthetic scan and
  manual decision entirely in the application, without a Notebook kernel.
- [Edit and analyze a starter experiment](starter-authoring.md) continues the
  installed quickstart in your own author folder with parameters, scans, analysis
  and retained results.

The old reference gallery is retired as teaching material; its remaining scripts
are temporary integration-test inputs, not author examples to copy. See the
[retirement inventory](../development/reference-gallery-retirement.md).
