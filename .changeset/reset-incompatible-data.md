Reset incompatible application data from the startup window

When old data prevents startup, choose an external backup folder and confirm
resetting the application's stored experiments, parameters, drafts and device
configuration. Backup failure leaves the data undeleted. An explicit skip-backup
option is available for that operation only. Source files, environments and the
application remain in place. Old-format backups are not promised to open in the
current version.
