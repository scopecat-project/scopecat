# Add a control-first device workbench

Keep controls and acquisition actions together, with independently visible control
and results areas, a resizable divider, separate scrolling and a compact-window
switch. Preserve mounted input, result and save state across layout and information
views without adding automatic refresh or generic stop behavior.

Keep the save and compact recent-result selector above bounded previews, while
retaining the full recent list below the curve. Narrow charts retain readable
plot space without loading full receipts or changing scientific coordinates.
