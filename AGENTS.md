# Repository conventions

- This project has one maintainer. Public changes use CI, self-review and squash
  merging; independent review approval is not required.
- APIs and internal designs are pre-stable. Update affected consumers when they
  change. Persistent scientific data follows the separate
  [data compatibility policy](docs/development/data-compatibility.md).
- Development commands and contribution guidance are in
  [the contributor guide](docs/development/index.md). For issue work, consult
  the current issue body and [platform status](docs/development/platform-status.md);
  distinguish implementation, distribution and acceptance.

This file contains stable repository-specific conventions. Update it only when
the user explicitly requests a change to repository instructions. Task progress
and implementation findings belong in the relevant issues or project documentation.
Do not use this file as a session memory or handoff log.
