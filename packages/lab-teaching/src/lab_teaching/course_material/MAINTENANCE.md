# 维护者专项：保留源码和恢复结果

备份与恢复使用普通应用的当前格式能力，步骤和边界见
[备份恢复指南](https://github.com/scopecat-project/scopecat/blob/main/docs/how-to/backup-and-restore.md)。
先确认应用实际数据位置并停止该应用；作者目录不拥有独立服务。

单独保留可编辑作者源码、Notebook 和自己的笔记。应用数据快照不承诺包含外部作者目录、
本地 Python 环境或外部依赖；离线恢复需要留存匹配的软件包。

恢复到新位置后先读取原 run ID、原 IQ 和原分析，不重新采集。
需要追加分析时，再显式登记恢复的源码位置和执行环境；原分析应继续可见。
已有独立项目保留原环境和数据，不自动迁移，也不覆盖原目录。
