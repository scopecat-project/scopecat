实验服务

登记已有实验项目

在该项目的 Python 环境中运行 scopecat app 项目目录。也可以通过 --python 指定实验环境，源码部署使用 --static-dir 指定已构建的 GUI。

登记不启动设备。点击打开工作台才会按项目已有设置启动服务；测量仍需在工作台提交。

更新实验环境

先结束测量并关闭 Notebook 连接，停止实验服务，再在原环境中更新软件。服务显示“未启动”后，点击“重新检查环境”；成功后再启动工作台。重新检查不会安装软件或启动服务。

检查失败时保留原登记，请查看操作日志，修复原环境后重试。若更换了解释器或 GUI 目录，请从可信的本机环境使用 scopecat app 项目目录 --python 解释器 --static-dir GUI目录 重新登记，并沿用原来的 --home 等管理入口参数。
