实验服务

更新实验环境

先结束测量、关闭 Notebook 服务和内核，再停止实验服务。在服务卡片中选择“更新实验室环境”，填写新的交付目录或固定构建目录；应用会准备新环境并保留原数据与旧环境。成功后重新打开工作台，并从作者目录运行 scopecat notebook；其他编辑器需选用新解释器。

只有维护者自行更改原环境或本机设置时才使用“重新检查环境”。失败和中断的处理方式见操作日志与帮助中的维护指南。
